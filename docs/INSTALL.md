# התקנה והפעלה — K-Droid Filter

## 1. התקנת ה-APK
העבר את קובץ ה-APK למכשיר והתקן. לבדיקות אפשר להשתמש ב-APK שנבנה ב-GitHub Actions
(לשונית Actions ← הריצה האחרונה ← Artifacts).

## 2. הפעלה כ-Device Owner
Device Owner חייב מכשיר **נקי** — בלי חשבון Google ובלי משתמשים נוספים. אם יש, בצע איפוס להגדרות יצרן ואל תוסיף חשבון בהגדרה.

### דרך א' — ADB (מחשב)
1. הפעל במכשיר: הגדרות ← אפשרויות מפתח ← USB Debugging.
2. חבר למחשב עם כבל.
3. הרץ:
   ```
   adb shell dpm set-device-owner com.kdroid.filter/.admin.AdminReceiver
   ```
4. חזור לאפליקציה ולחץ "בדוק מצב". היא תאמת שההפעלה הצליחה.

### דרך ב' — Root (ללא מחשב)
1. ודא שיש Root במכשיר.
2. באשף, לחץ "הפעל דרך Root". האפליקציה תריץ את הפקודה ותאמת את התוצאה.
3. אם נכשל (למשל קיים חשבון במכשיר) — תוצג הודעה כנה; נסה דרך ADB על מכשיר נקי.

## 3. הגדרת קוד מנהל
רק לאחר זיהוי Device Owner תתבקש לבחור קוד. הוא יידרש בכל כניסה לאזור הניהול.

## 4. חיבור לשרת (אופציונלי)
1. בלוח הבקרה, כרטיס "שרת ושליטה מרחוק", הזן את כתובת השרת (https).
2. לחץ "רישום לשרת" — יוצג מספר מכשיר וקוד קישור.
3. באתר הניהול הזן את קוד הקישור כדי לשייך את המכשיר.

## 5. הפעלת הגנות
- **חומת אש:** לשונית "חומת אש" ← הדלק "הגנת רשת".
- **אישור אפליקציות:** לשונית "אפליקציות" ← אפשר אינטרנט לאפליקציות הרצויות.
- **הגבלות:** לשונית "הגבלות" ← הדלק מתגים לפי הצורך.
- **קיוסק:** לשונית "הגבלות" ← כרטיס קיוסק ← הדלק, ובחר אפליקציות ב"אפליקציות" (הצג במסך הבית).

## חשוב
- אל תפעיל קיוסק לפני שווידאת שמצב התחזוקה עובד (יציאה עם קוד).
- במכשיר ללא Device Owner חלק מהיכולות לא יחולו — המסכים מציגים זאת בבירור.
