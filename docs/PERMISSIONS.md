# הרשאות — K-Droid Filter

כל הרשאה והסיבה לה. אין הרשאות מיותרות.

| הרשאה | סוג | למה היא נדרשת |
|---|---|---|
| `INTERNET` | רגילה | סנכרון עם שרת הניהול (HTTPS בלבד) |
| `RECEIVE_BOOT_COMPLETED` | רגילה | החזרת חומת האש והקיוסק לאחר אתחול |
| `FOREGROUND_SERVICE` | רגילה | הרצת שירות חומת האש (VPNService) |
| `QUERY_ALL_PACKAGES` | מיוחדת | גילוי כל האפליקציות המותקנות לניהול |
| `BIND_VPN_SERVICE` | חתימה/מערכת | חומת אש לפי אפליקציה דרך VPNService |
| `BIND_DEVICE_ADMIN` | חתימה/מערכת | פעולות Device Owner (הגבלות, קיוסק, אפליקציות) |

הערות:
- `QUERY_ALL_PACKAGES` נדרשת מ-Android 11 כדי לראות את רשימת האפליקציות המלאה. זו דרישת מוצר מרכזית (ניהול אפליקציות).
- אין בקשת מצלמה/מיקרופון/מיקום כהרשאות אפליקציה — הן מנוהלות כהגבלות מערכת, לא כצריכה.
- התקשורת עם השרת נאכפת כ-HTTPS בלבד (`network_security_config`, `usesCleartextTraffic=false`).
