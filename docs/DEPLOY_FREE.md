# פריסה חינמית — Render + Neon

ללא עלות וללא דומיין. Render נותן כתובת HTTPS חינם. השרת יוצר את מסד הנתונים והמנהל לבד בעלייה.

## שלב 1 — מסד נתונים חינם ב-Neon
1. היכנס ל-neon.com והירשם (אפשר עם חשבון GitHub).
2. צור Project חדש.
3. העתק את **Connection String** (מחרוזת שמתחילה ב-`postgres://...` וכוללת `sslmode=require`).

## שלב 2 — שרת ואתר ב-Render
1. היכנס ל-render.com והירשם (עם GitHub).
2. לחץ **New ← Blueprint**.
3. חבר את המאגר `c0504190601-web/SHN` ובחר את ענף העבודה.
4. Render יזהה את הקובץ `render.yaml` אוטומטית.
5. הזן שני ערכים כשתתבקש:
   - `DATABASE_URL` — הדבק את מחרוזת החיבור מ-Neon.
   - `ADMIN_PASSWORD` — בחר סיסמת מנהל חזקה.
6. לחץ **Apply / Deploy**.

לאחר דקה-שתיים תקבל כתובת כמו `https://kdroid-server.onrender.com`.
זהו — האתר חי שם, והשרת יצר את הטבלאות ואת המנהל (`admin` + הסיסמה שבחרת) לבד.

## שלב 3 — חיבור האפליקציה
1. פתח את האפליקציה במכשיר ← לוח בקרה ← "שרת ושליטה מרחוק".
2. הזן את כתובת Render (`https://kdroid-server.onrender.com`).
3. "רישום לשרת" ← יוצג קוד קישור.
4. היכנס לאתר (אותה כתובת), התחבר עם `admin` והסיסמה, והזן את קוד הקישור.

## מה לדעת על התוכנית החינמית
- השרת "נרדם" אחרי ~15 דקות ללא פעילות; הבקשה הראשונה אחריה לוקחת 30–60 שניות. מכיוון שהסנכרון תקופתי — זה בסדר.
- מסד הנתונים ב-Neon נשאר (לא נמחק), אך גם הוא נרדם ומתעורר.
- לשימוש יומיומי שסומכים עליו, מעבר ל-VPS (ראה `server/README.md`) נותן יציבות ומהירות, בלי שינוי קוד.

## שדרוג ל-VPS בהמשך (אופציונלי)
אותו קוד בדיוק רץ על VPS. ראה `server/README.md` ו-`docs/` להוראות Hetzner + Nginx + TLS.
